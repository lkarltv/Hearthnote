This synthetic library shows how a coach might support someone exploring a career move. The examples are fictional, and the worksheets can be copied for a session.

| If the client is asking… | Start with |
| --- | --- |
| What would suit me better? | Career direction / What makes work a good fit |
| How do I explain what I can do? | Career direction / Translate experience into skills |
| How can I learn about a role before applying? | Job search / An informational conversation |
| What should I say when asked for an example? | Interviews / Build an interview story |

A useful session ending is one concrete action and a date to review what the client learned.
